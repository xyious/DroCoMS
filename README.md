# DroCoMS
## Blog/website using drogon framework
This is meant to be a complete and usable content management system. 

## Installation
Clone drogonframework: https://github.com/drogonframework/drogon
Install dependencies (https://drogonframework.github.io/drogon-docs/#/ENG/ENG-02-Installation)
(Arch) sudo pacman -S git gcc make cmake jsoncpp zlib openssl
Build and install drogon before cloning this repo and going to the build folder to
cmake ..
make

You'll (hopefully) have an executable that you can run. 
You need to configure the database in config.json and create the database before running the server and then the InstallDB script (baseurl/InstallDB).
